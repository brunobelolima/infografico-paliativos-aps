# Infográfico - Abordagem Paliativa na APS

Infográfico interativo sobre os resultados do **II Curso de Abordagem
Paliativa na Atenção Primária à Saúde**, ministrado por Telessaúde pelo projeto
TeleNordeste-BP.

O material apresenta:

- estrutura e carga horária do curso;
- inscrições, participação e taxa de retenção;
- resultados de conhecimento e autoeficácia;
- Net Promoter Score (NPS);
- feedbacks dos participantes;
- sugestões do pesquisador;
- links para instituições, vídeo e dissertação completa;
- layout responsivo para computadores e dispositivos móveis.

- React
- Next.js
- TypeScript
- CSS responsivo
- vinext / Vite

## Executar localmente

Requisito: Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

Abra o endereço exibido no terminal.

## Verificar a versão de produção

```bash
npm run build
```

## Principais arquivos

- `app/page.tsx`: conteúdo, estrutura e interações;
- `app/globals.css`: identidade visual e responsividade;
- `public/`: imagens e logotipos;
- `app/layout.tsx`: metadados e estrutura geral.

## Publicar no GitHub

1. Crie um repositório vazio no GitHub.
2. Extraia este pacote e abra a pasta no terminal.
3. Execute:

```bash
git init
git add .
git commit -m "Publica infográfico interativo"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
git push -u origin main
```
